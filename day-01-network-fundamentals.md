# Day 01 - Network Fundamentals

## What I Learned

### 1. Network Basics
- A network is a group of connected devices
- Purpose: communication + resource sharing

### 2. Network Components
- Router → connects networks
- Switch → connects devices in LAN
- Firewall → security layer

### 3. Network Types
- LAN → Local Area Network
- WAN → Wide Area Network
- MAN → Metropolitan Area Network

### 4. Network Topologies
- Star → centralized (most common)
- Bus → single backbone
- Ring → circular connection

### 5. Wired vs Wireless
- Wired → stable, faster
- Wireless → flexible, less stable

### Key Insight
Understanding topology is important for performance and troubleshooting.
