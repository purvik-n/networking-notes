# 🖥️ Layers 5, 6, and 7 (Upper OSI Layers)

## Layer 5 — Session Layer
- **Function:** Establishes, manages, maintains, and terminates communication sessions between applications on different devices.
- **Mechanisms:** Checkpointing, synchronization tokens, RPC (Remote Procedure Call).

## Layer 6 — Presentation Layer
- **Function:** Translates, formats, encrypts, and compresses data so that the application layer can understand it.
- **Key Roles:**
  - **Data Translation:** ASCII, Unicode, EBCDIC.
  - **Compression:** Gzip, Brotli.
  - **Encryption/Decryption:** SSL/TLS syntax handling.

## Layer 7 — Application Layer
- **Function:** Directly interacts with user software applications to provide network communication services.
- **Key Protocols:** HTTP/HTTPS, DNS, SSH, FTP, SMTP, IMAP, SNMP, Telnet.
