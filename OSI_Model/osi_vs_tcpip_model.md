# ⚖️ OSI Model vs TCP/IP Model

The TCP/IP model is the practical implementation used on the internet today, condensing OSI's 7 layers into 4 layers:

| OSI 7-Layer Model | TCP/IP 4-Layer Model | Protocols in Layer |
| :--- | :--- | :--- |
| **Layer 7: Application** | **Application Layer** | HTTP, HTTPS, DNS, SSH, FTP, SMTP |
| **Layer 6: Presentation** | | |
| **Layer 5: Session** | | |
| **Layer 4: Transport** | **Transport Layer** | TCP, UDP |
| **Layer 3: Network** | **Internet Layer** | IP (IPv4/IPv6), ICMP, ARP |
| **Layer 2: Data Link** | **Network Access Layer** (Link Layer) | Ethernet (802.3), Wi-Fi (802.11), MAC |
| **Layer 1: Physical** | | |
