# 🌐 Layer 3 (Network) & Layer 4 (Transport)

## Layer 3 — Network Layer
- **Function:** Responsible for logical addressing, path determination, routing packets across multiple interconnected networks.
- **PDU:** Packet.
- **Addressing:** Logical IP Addresses (IPv4 / IPv6).
- **Devices:** Routers, Layer 3 Switches.
- **Key Protocols:** IP, ICMP, ARP, BGP, OSPF.

## Layer 4 — Transport Layer
- **Function:** End-to-end communication, segmentation, error recovery, flow control, and port-based multiplexing.
- **PDU:** Segment (TCP) or Datagram (UDP).
- **Addressing:** Port numbers (e.g., Port 80, 443, 22).
- **Key Protocols:** TCP, UDP.
