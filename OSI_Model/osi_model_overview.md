# 📚 The OSI 7-Layer Reference Model

The Open Systems Interconnection (OSI) model is a conceptual framework developed by the ISO to standardize network communication into 7 distinct layers.

```text
Layer 7: Application    (Data)
Layer 6: Presentation   (Data)
Layer 5: Session        (Data)
Layer 4: Transport      (Segments / Datagrams)
Layer 3: Network        (Packets)
Layer 2: Data Link      (Frames)
Layer 1: Physical       (Bits)
```
