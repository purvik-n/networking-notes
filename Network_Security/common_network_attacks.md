# ⚠️ Common Network Attack Vectors

## 1. Denial of Service (DoS & DDoS)
Flooding a network, server, or application with overwhelming volume of malicious traffic to make it unavailable to legitimate users (e.g., SYN Flood, UDP Amplification, HTTP Flood).

## 2. Man-in-the-Middle (MitM)
An attacker secretly intercepts and relays communications between two parties who believe they are communicating directly with each other.

## 3. ARP Spoofing (ARP Poisoning)
Attacker sends forged ARP messages across a local area network to associate the attacker's MAC address with the IP address of a legitimate default gateway.

## 4. DNS Cache Poisoning (DNS Spoofing)
Injecting corrupt DNS data into the resolver cache so that queries for legitimate domains resolve to malicious IP addresses.
